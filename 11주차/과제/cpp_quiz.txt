3번

다음 코드의 출력 결과는?

#include <stdio.h>

struct Student {
    int score;
};

int main(void) {
    struct Student a = {80};
    struct Student b = a;
    b.score = 95;
    printf("%d %d", a.score, b.score);
    return 0;
}

① 80 95

② 95 95

③ 80 80

④ 95 80

5번

다음 코드의 출력 결과는?

#include <stdio.h>

struct Student {
    int score;
};

void change(struct Student s) {
    s.score = 100;
}

int main(void) {
    struct Student s = {60};
    change(s);
    printf("%d", s.score);
    return 0;
}

① 100

② 60

③ 0

④ 오류 발생

2번: ④
