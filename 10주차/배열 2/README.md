## 실행

원하는 파일 하나를 C11로 컴파일합니다.

```sh
gcc -std=c11 jungol_00.c -o solution
```

한글 출력이 있는 파일은 UTF-8 환경에서 사용합니다. 입력 예시에 함께 표시된 안내 문구는 프로그램에서 출력하며, 사용자는 숫자만 입력합니다.

## 확인

- GCC C11, `-Wall -Wextra -Werror`로 24개 파일 컴파일 완료
- 공식 예제에 기반한 실행 검사와 경계 사례: 총 27개 통과
- 정올 온라인 채점에는 제출하지 않았습니다.
